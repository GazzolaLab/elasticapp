## Utilities

Every project starts simple with minimal utilities, and over time stuff gets crammed into it.
`Elastica++` is no different. This folder contains a litany of miscellaneous utilities to make the code simpler and
easier to read, especially because `C++14` had good, but not great support for lots of things.

My advice to anyone reading this code is to have a "peek when needed" attitude---usually the names are descriptive
enough to give you an inkling of what the utilities are being used for.
